1. Close verification gaps: reproducible container build, browser journey in CI, backup/restore exercise and measured 30-project/300-milestone/500-edge rendering.
2. Improve graph readability: label collision handling, dense-edge bundling, offscreen culling, keyboard traversal and accessibility review.
